🏠 Unit Types

Add the unit types found in your building (e.g. 1BR/1BA, 2BR/2BA). You'll use these when assigning a type to each suite, and we'll use them to calculate how many smart devices you'll need. You can update this list anytime from Suites.

🏠 Place Suite

No unit types defined yet — click Manage Unit Types in the Suites panel to add some.

IoT Devices

Select which in-unit smart devices are included for every suite. Each selection rolls one line into the Smart Apartment section of the BOM, with quantity equal to the suite count.

Selected devices appear as columns on the Unit Types modal, where you set the per-suite count for each unit type. Unchecking a device removes its column; per-unit-type values will reset to 1 if the device is re-enabled later.
